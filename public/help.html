REVIEW / 說明 / 確認方法

A lens, not an approval.

Deliberate checks

In a future installed Forge issue panel, enter 1–5 issue keys and choose Check selected issues. Only status, updated metadata and due date are requested through the current user's Jira permissions. There are no automatic issue reads, retries or writes.

After all reads succeed, download a snapshot. Import it and check again to compare selected fields and freshness. An unavailable issue must hide its prior reference fields. Page state lives only in memory.

This is a local build with an unregistered placeholder app ID. Real Forge rendering, permissions, file import/download, installation and billing have not been verified. This help page does not initiate a connection.

明確觸發的檢查

未來安裝到 Forge 工作項目面板後，輸入 1–5 個工作項目代碼，按下檢查按鈕。程式僅依目前使用者的 Jira 權限讀取狀態、更新時間與到期日，不會自動讀取、重試或寫入工作項目。

全部讀取成功後可下載快照。匯入快照再檢查，可比較指定欄位與新鮮度；無法讀取的項目不得顯示舊快照欄位。頁面資料僅保存在記憶體。

目前僅完成本機建置，應用程式 ID 為未註冊的占位符；尚未驗證真實 Forge 畫面、權限、檔案匯入下載、安裝或帳務。本說明頁不會啟動連線。

明示的な確認

将来 Forge の課題パネルにインストールした際は、1〜5 件の課題キーを入力し、確認ボタンを押してください。現在のユーザーの Jira 権限で状態・更新日時・期日のみを取得します。課題の自動取得、再試行、書き込みは行いません。

全件の取得が成功したらスナップショットを保存できます。読み込んで再確認すると対象フィールドと鮮度を比較できます。取得できない課題の過去の参照データは表示しません。ページの状態はメモリ内のみです。

現在はローカルビルドで、アプリ ID は未登録のプレースホルダーです。実際の Forge 表示、権限、ファイル操作、インストール、課金は未検証です。この説明ページは接続を開始しません。

Trust boundaries

A checksum detects accidental changes, not identity or approval. Imported times and provenance are untrusted. Scope selection may omit dependencies. A failed read hides reference fields in this view, but cannot revoke a file already downloaded or prevent inspection of an imported local file. Do not import or distribute restricted data.

Forge issue panels are visible only to users who can edit the current issue. Read-only API scope does not grant Jira browse or issue-security permissions.
