# Support

Use [GitHub Issues](https://github.com/CarsonCCHsieh/handoff-lens/issues) for
questions, bug reports and feature requests.

Include the browser/version, interface language, action taken, expected result
and observed result. Reproduce with authored demonstration data where possible.
The app's short error label is enough; it does not require a raw Jira response.

Do not attach API tokens, passwords, account/site identifiers, real issue keys,
snapshot files or screenshots containing restricted information. Issues may be
public. For a sensitive security or privacy concern, open a minimal issue asking
for a private reporting route without posting the sensitive details.

The panel requires permission to edit the current Jira issue. Reads also depend
on the current user's browse/security permissions. Handoff Lens cannot grant
additional Jira access. Checks are manual and limited to five issues; importing
a reference or switching language does not refresh Jira data.

[README.md](README.md) explains setup, [JUDGING.md](JUDGING.md) distinguishes
completed and pending verification, and [PRIVACY.md](PRIVACY.md) describes data
handling.
