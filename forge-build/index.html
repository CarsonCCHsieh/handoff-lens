HandoffLens

Use Handoff Lens

Open Handoff Lens from a Jira issue you can browse and edit. Enter 1–5 issue keys and choose Check selected issues. The app reads workflow category, update time and due date through your current Jira permissions. It does not automatically read, retry or write to issues.

After all reads succeed, you can download a snapshot. Import a file, or paste its JSON and choose Import pasted JSON. After a successful import, choose Use reference scope, then check again. Importing alone starts no Jira reads. Reference details appear in the report only after the corresponding current issue can be read; unavailable entries withhold their prior details and disable a new snapshot download.

Field differences and time-derived freshness are separate signals. Freshness uses a 48-hour threshold, and due dates use UTC calendar dates. A clear signal covers only the selected metadata; it does not establish complete dependencies, acceptance or handoff approval.

Snapshot files can contain sensitive issue keys, metadata and a workspace fingerprint. A checksum detects content mismatch, not authorship or approval. Imported times and source claims are untrusted. Only import or share data you are authorized to use; this view cannot revoke a file someone already has.

Working state stays in page memory. Clear this view removes the current input, reference and results; it does not securely erase memory, downloaded files or Jira data. Switching English, 繁體中文 or 日本語 changes the labels without reading Jira again. Read-only app scope does not grant browse or issue-security access.

使用 Handoff Lens

從你有權瀏覽及編輯的 Jira 工作項目開啟 Handoff Lens。輸入 1–5 個工作項目代碼，再按下核對選定項目。程式依目前的 Jira 權限讀取工作流程狀態分類、更新時間與到期日，不會自動讀取、重試或寫入工作項目。

全部讀取成功後可下載快照。匯入檔案，或貼上 JSON 後按下匯入貼上的 JSON。匯入成功後選擇使用參考範圍，再明確執行檢查；單純匯入不會讀取 Jira。只有能重新讀取的項目，才會在報告中顯示對應參照欄位；無法讀取的項目會隱藏舊參照資料，並停用新快照下載。

欄位變動與隨時間計算的資料新鮮度是不同訊號。新鮮度以 48 小時為門檻，到期日依 UTC 日曆日期比較。訊號正常僅涵蓋所選資料，不代表相依項目完整、工作已驗收或交接已核准。

快照可能含有敏感的工作項目代碼、資料及工作區指紋。檢查碼可發現內容不符，不能證明作者或核准狀態；匯入時間與來源宣稱也不能視為可信憑據。僅匯入或分享你有權使用的資料；此畫面無法撤回別人已持有的檔案。

操作資料僅保存在頁面記憶體。清除此檢視會移除目前輸入、參照與結果，但不會安全抹除記憶體、下載檔案或 Jira 資料。切換 English、繁體中文或日本語只會改變介面文字，不會重新讀取 Jira。應用程式的唯讀權限不會額外授予瀏覽或工作項目安全性權限。

Handoff Lens の使い方

閲覧と編集の権限がある Jira 課題から Handoff Lens を開きます。1〜5 件の課題キーを入力し、選択項目を確認してください。現在の Jira 権限でワークフローの状態カテゴリ、更新日時、期日のみを取得します。課題の自動取得、再試行、書き込みは行いません。

全件の取得が成功したらスナップショットを保存できます。ファイルを読み込むか、JSON を貼り付けて貼り付けた JSON を読み込むを押します。読み込みが成功したら参照の範囲を使用してから再確認します。読み込みだけでは Jira に問い合わせません。現在の課題を取得できた場合に限り、対応する参照情報を結果に表示します。取得できない課題の過去の参照情報は表示せず、新しいスナップショットの保存も無効になります。

フィールドの差分と時間の経過による鮮度は別のシグナルです。鮮度の基準は 48 時間、期日の比較は UTC の日付です。問題がないという表示は選択した情報だけを対象とし、依存関係の完全性、受け入れや引き継ぎの承認を示すものではありません。

スナップショットには機密性のある課題キー、メタデータ、ワークスペースの識別用ハッシュが含まれる場合があります。チェックサムは内容の不一致を検出しますが、作成者や承認を証明しません。読み込んだ日時や出所の申告も保証されません。権限のあるデータだけを読み込み、共有してください。この画面から既に保存されたファイルを取り消すことはできません。

作業状態はページのメモリ内だけに保持します。この画面をクリアすると入力、参照、結果を削除しますが、メモリ、保存済みファイル、Jira データを安全に消去するものではありません。English、繁體中文、日本語の切り替えでは表示言語だけが変わり、Jira を再取得しません。アプリの読み取り専用スコープによって閲覧権限や課題セキュリティの権限が付与されることはありません。
